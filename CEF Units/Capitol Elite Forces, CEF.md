The Capitol Elite Forces are specialized units loyal to the emperor only, their ranks contain 2 sections, Alive & Undead.

The alive forces are willing to lay down their lives for the emperor knowing they will come back undead to serve him longer.

# CEF Troop Progression

## LIGHT TIER (Guard / Archer)
- Specialize → Skirmisher → Tracker
- Upgrade → Medium (Footman / Bowman / Arbalist)
- Pivot → Logistics (Signal, Supply, Medic)

## MEDIUM TIER (Footman / Bowman / Arbalist)
- Specialize → Pathfinder → Tracker
- Pivot → Cavalry (Trainee → Rider → Lancer / Knight)
- Pivot → Support (Surgeon, Sapper, Quartermaster)
- Upgrade → Heavy (Man-at-Arms)

## HEAVY TIER (Man-at-Arms)
- Specialize → Shieldwarden / Breaker Infantry
- Pivot → Arcane Support (Rune-Scribe, Shieldbearer)
- Upgrade → Command

## COMMAND TIER
- Sergeant → Lieutenant → Captain → Commander → High Marshal
- Arcane Track → Arcane Lieutenant → Arcane Captain → Arcane Marshal
