The Verdagor works a bit different then most DnD monsters, it's health pool is somewhat split between his parts. each having its own resistance.

| Part  | HP (Blooming) | Rolled | Bludgeoning | Piercing | Slashing | Fire   | Magic |
| ----- | ------------- | ------ | ----------- | -------- | -------- | ------ | ----- |
| Chest | 100           | 18d10  | ★★          | ★★★(★)   | ★★       | ★★★(★) | ★★    |
| Claws | 100           | 18d10  | ★★★         | ★        | ★        | ★      | ★★    |
| Head  | 100           | 18d10  | ★★★         | ★★       | ★        | ★★     | ★★    |
| Legs  | 100           | 18d10  | ★           | ★★       | ★★★      | ★★     | ★★    |
| Tail  | 100           | 18d10  | ★           | ★        | ★★★      | ★★     | ★★    |

 / = **Invulnerable**
★= **Resistant**, 50% damage.
★★ = **Normal**, 100% damage.
★★★ = **Vulnerability**, 200% damage.
(★) = Resistance after part break. (Blooming only)

If a part goes to 0 HP it breaks, effecting the Verdagor

| Part  | On Break                                               |
| ----- | ------------------------------------------------------ |
| Head  | Lose poison on Grasping Bite, Pinning Vault, Acid Spit |
| Tail  | No more Twisting Pounce, Lair poison = 1d4-2           |
| Claws | killing claw -> 1d8 +3, No Malicious Sweep             |
| Legs  | Speed 45ft -> 30ft, Falls prone                        |
| Chest | No more False Appearance, No Flower Petals             |
If a broken part gets damaged the health affects the main pool. If the main pool is empty the creature dies, the main pool is all the part's HP combined.
