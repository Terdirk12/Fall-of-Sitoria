The Nythrax works a bit different then most DnD monsters, it's health pool is somewhat split between his parts. each having its own resistance.

| Part     | HP   | Taken | Bludgeoning | Piercing | Slashing | Fire  | Lightning | Necrotic | Cold   |
| -------- | ---- | ----- | ----------- | -------- | -------- | ----- | --------- | -------- | ------ |
| Frills L | 200  |       | ★★★         | ★★       | ★★       | ★(★★) | /         | ★(★★★)   | ★★     |
| Frills R | 200  |       | ★★★         | ★★       | ★★       | ★(★★) | /         | ★(★★★)   | ★★     |
| Tail     | 200  |       | ★           | ★        | ★★★      | ★     | /         | ★★       | ★★★(★) |
| Head     | 200  |       | ★★★         | ★        | ★★       | ★(★★) | /         | ★★       | ★★★(★) |
| Body     | 200  |       | ★★          | ★★       | ★★       | ★     | /         | ★★       | ★★★(★) |
| HP       | 1000 |       |             |          |          |       |           |          |        |
All unspecified damage types are: ★★

/ = **Invulnerable**
★= **Resistant**, 50% damage.
★★ = **Normal**, 100% damage.
★★★ = **Vulnerability**, 200% damage.
(★) = Resistance when hovering

If a part goes to 0 HP it breaks, effecting the Nythrax

| Part     | On Break                                                    |
| -------- | ----------------------------------------------------------- |
| Frills L | -20 Hover speed \| if both frills break, cant hover anymore |
| Frills R | -20 Hover speed \| if both frills break, cant hover anymore |
| Tail     |                                                             |
| Head     |                                                             |
| Body     |                                                             |
If a broken part gets damaged the health affects the main pool. If the main pool is empty the creature dies, the main pool is all the part's HP combined.
