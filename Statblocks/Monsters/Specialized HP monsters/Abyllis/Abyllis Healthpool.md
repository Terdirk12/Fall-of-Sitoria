The Abyllis works a bit different then most DnD monsters, it's health pool is somewhat split between his parts. each having its own resistance.

| Part           | HP  | Taken | Bludgeoning | Piercing | Slashing | Magic | Fire | Cold |
| -------------- | --- | ----- | ----------- | -------- | -------- | ----- | ---- | ---- |
| Eye            | 115 |       | ★★★         | ★★★      | ★        | /     | /    | ★    |
| R Tentacle     | 115 |       | /           | ★        | ★★★      | ★★    | ★    | ★★★  |
| L Tentacle     | 115 |       | /           | ★        | ★★★      | ★★    | ★    | ★★★  |
| Body           | 115 |       | ★★          | ★★       | ★★       | /     | /    | ★    |
| Rear Tentacles | 115 |       | /           | ★        | ★★★      | ★★    | ★    | ★★★  |
| HP             | 575 |       |             |          |          |       |      |      |
All unspecified damage types are: ★★

 / = **Invulnerable**
★= **Resistant**, 50% damage.
★★ = **Normal**, 100% damage.
★★★ = **Vulnerability**, 200% damage.
(★) = Resistance after part break.

If a part goes to 0 HP it breaks, effecting the Verdagor

| Part           | On Break                                  |
| -------------- | ----------------------------------------- |
| Eye            | Blind unless Stealing Visage              |
| R Tentacle     | No ray of Bewildered - Addled             |
| L Tentacle     | No Ray of Enfeebled - Clumsy              |
| Body           | 90 damage spread out over remaining parts |
| Rear Tentacles | movement = 15ft                           |
If a broken part gets damaged the health affects the main pool. If the main pool is empty the creature dies, the main pool is all the part's HP combined.
