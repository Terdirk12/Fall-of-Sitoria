The Skelkie works a bit different then most DnD monsters, it's health pool is somewhat split between his parts. each having its own resistance.

| Part   | HP  | Bludgeoning | Piercing | Slashing | Nectrotic | Radiant | Force | Magic |
| ------ | --- | ----------- | -------- | -------- | --------- | ------- | ----- | ----- |
| Face   | 60  | ★★          | ★★★      | ★★       | ★         | ★★★     | ★★    | ★★    |
| Shell  | 100 | ★★★         | ★        | ★        | ★★        | ★★      | ★★    | ★★    |
| Frills | 90  | ★★          | ★★       | ★★       | ★         | ★★★     | ★★★   | ★★    |
| Body   | 50  | ★★          | ★★       | ★★       | ★         | ★★★     | ★★★   | ★★    |
| HP     | 400 |             |          |          |           |         |       |       |
All unspecified damage types are: ★★

/ = **Invulnerable**
★= **Resistant**, 50% damage.
★★ = **Normal**, 100% damage.
★★★ = **Vulnerability**, 200% damage.
(★) = Resistance after part break.


If a part goes to 0 HP it breaks, effecting the Skelkie

| Part   | On Break                                                                                                                            |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Face   | Loses Necroray                                                                                                                      |
| Shell  | AC −2; can no longer retreat into its shell for protection                                                                          |
| Frills | Newly summoned undead spawn with half their normal HP, rounded down                                                                 |
| Body   | Clears all summoned undead when broken; retracts, then re-emerges before summoning can resume; respawns with (max_hp = max_hp + 25) |

If a broken part gets damaged the health affects the main pool. If the main pool is empty the creature dies, the main pool is all the part's HP combined.
